# Curated Style Profiles

15 style profiles for frontend design direction. Each profile provides a cohesive starting point — adapt to project needs, don't copy verbatim.

---

## 1. Clinical Precision

**Mood**: Clean, trustworthy, institutional
**Best for**: Biotech, healthcare, research platforms
**Colors**: `#0F172A` (ink) · `#1E293B` (panel) · `#0EA5E9` (accent) · `#10B981` (success) · `#F8FAFC` (surface) · `#94A3B8` (muted)
**Fonts**: Inter (body) + DM Serif Display (headings)
**Layout**: Generous whitespace, card-based, left-aligned content blocks
**Motion**: Subtle fade-up reveals only. No bounce, no elastic.

## 2. Dark Observatory

**Mood**: Deep, data-rich, focused
**Best for**: Scientific visualization, data dashboards, monitoring tools
**Colors**: `#0A0E1A` (bg) · `#111827` (panel) · `#60A5FA` (accent) · `#34D399` (success) · `#EF4444` (danger) · `#E2E8F0` (text)
**Fonts**: Inter (body) + JetBrains Mono (data/code)
**Layout**: Dense grid, full-viewport panels, minimal chrome
**Motion**: Spring physics for interactive, linear for process animation.

## 3. Soft Editorial

**Mood**: Warm, approachable, narrative
**Best for**: Personal portfolios, blogs, case study sites
**Colors**: `#1A1A2E` (ink) · `#F5F0EB` (warm surface) · `#D4A574` (accent) · `#7C6F64` (muted) · `#2D2D2D` (heading)
**Fonts**: Playfair Display (headings) + Source Sans 3 (body)
**Layout**: Single-column editorial, wide margins, large typography
**Motion**: Slow fade reveals (600ms+), parallax-free, reading-pace transitions.

## 4. Neon Terminal

**Mood**: Technical, hacker-aesthetic, high-contrast
**Best for**: Developer tools, CLI documentation, tech portfolios
**Colors**: `#0D1117` (bg) · `#161B22` (panel) · `#58A6FF` (link) · `#3FB950` (success) · `#F0883E` (warning) · `#C9D1D9` (text)
**Fonts**: JetBrains Mono (headings + code) + Inter (body)
**Layout**: Monospace-aligned grids, terminal-inspired sections, code-block prominence
**Motion**: Cursor blink, typewriter text reveals, instant state transitions.

## 5. Mineral Minimal

**Mood**: Ultra-clean, quiet confidence, premium
**Best for**: SaaS landing pages, product marketing, design agency
**Colors**: `#FAFAFA` (bg) · `#171717` (ink) · `#404040` (body) · `#A3A3A3` (muted) · `#2563EB` (CTA)
**Fonts**: Geist Sans (body) + Geist Sans (headings, weight 600-800)
**Layout**: Massive whitespace, centered hero, asymmetric feature sections
**Motion**: Scroll-triggered reveals, subtle hover lifts, no color animations.

## 6. Research Canvas

**Mood**: Academic, structured, information-dense
**Best for**: Research groups, academic portfolios, publication sites
**Colors**: `#FFFFFF` (bg) · `#1F2937` (ink) · `#4F46E5` (accent) · `#6B7280` (muted) · `#F3F4F6` (code bg) · `#DC2626` (important)
**Fonts**: Literata (body) + Space Grotesk (headings) + Fira Code (notation)
**Layout**: Two-column with sidebar navigation, footnotes, citation-style references
**Motion**: None or minimal. Content is the interaction.

## 7. Gradient Dusk

**Mood**: Modern, vibrant, energetic
**Best for**: AI/ML products, startup launches, creative tools
**Colors**: `#0F0F23` (bg) · `#1A1A3E` (panel) · `#818CF8` (primary) · `#F472B6` (secondary) · `#FDE68A` (accent) · `#E2E8F0` (text)
**Fonts**: Plus Jakarta Sans (body) + Sora (headings)
**Layout**: Full-bleed hero with gradient mesh, overlapping sections, diagonal flows
**Motion**: Scroll-linked color shifts, staggered card reveals, hover glow effects.

## 8. Brutalist Function

**Mood**: Raw, honest, anti-design
**Best for**: Personal sites, experimental projects, developer blogs
**Colors**: `#FFFFFF` (bg) · `#000000` (ink) · `#FF0000` (accent) · `#0000FF` (link) · `#CCCCCC` (border)
**Fonts**: Space Mono (everything) or system-ui
**Layout**: Visible grid, exposed borders, no border-radius, raw HTML energy
**Motion**: None. Hover = underline. That's it.

## 9. Warm Craft

**Mood**: Handmade, organic, inviting
**Best for**: Non-profit, education, community platforms
**Colors**: `#FFF8F0` (bg) · `#2D1B0E` (ink) · `#B45309` (accent) · `#78716C` (muted) · `#FBBF24` (highlight) · `#365314` (success)
**Fonts**: Merriweather (body) + Outfit (headings)
**Layout**: Rounded cards, generous padding, asymmetric image placement
**Motion**: Gentle fade-ins, no spring physics, warm easing curves.

## 10. Steel Dashboard

**Mood**: Professional, efficient, enterprise
**Best for**: B2B SaaS, admin panels, internal tools
**Colors**: `#F8FAFC` (bg) · `#FFFFFF` (card) · `#0F172A` (ink) · `#3B82F6` (primary) · `#64748B` (secondary) · `#E2E8F0` (border)
**Fonts**: Inter (everything)
**Layout**: Sidebar + top bar, card grid, data tables, consistent 8px spacing
**Motion**: Instant transitions (150ms max). Skeleton loaders for async content.

## 11. Midnight Luxe

**Mood**: Premium, exclusive, high-end
**Best for**: Fintech, luxury SaaS, portfolio for design/architecture
**Colors**: `#09090B` (bg) · `#18181B` (panel) · `#D4AF37` (gold accent) · `#FAFAFA` (text) · `#71717A` (muted)
**Fonts**: Cormorant Garamond (headings) + Inter (body)
**Layout**: Full-bleed imagery, text overlays, cinematic sections
**Motion**: Slow reveals (800ms), scale-up on scroll, elegant hover underlines.

## 12. Pastel Lab

**Mood**: Playful, approachable, friendly
**Best for**: EdTech, wellness apps, onboarding flows
**Colors**: `#FEFCE8` (bg) · `#1E1B4B` (ink) · `#A78BFA` (primary) · `#34D399` (success) · `#FB923C` (accent) · `#FDA4AF` (highlight)
**Fonts**: Nunito (body) + Fredoka (headings)
**Layout**: Rounded everything (xl+), illustration-heavy, centered content
**Motion**: Bouncy springs (for non-scientific contexts), playful hover animations.

## 13. Arctic Clarity

**Mood**: Cold, precise, Scandinavian
**Best for**: Analytics tools, documentation sites, developer platforms
**Colors**: `#F0F4F8` (bg) · `#1A202C` (ink) · `#2B6CB0` (accent) · `#718096` (muted) · `#FFFFFF` (card) · `#E2E8F0` (border)
**Fonts**: IBM Plex Sans (body) + IBM Plex Mono (code)
**Layout**: Clean grids, ample negative space, left-aligned, no decorative elements
**Motion**: Fade only (200ms). No transforms, no springs.

## 14. Biotech Frontier

**Mood**: Cutting-edge, credible, forward-looking
**Best for**: Gene therapy, precision medicine, biotech startups
**Colors**: `#0C1222` (bg) · `#1A2744` (panel) · `#06B6D4` (primary/cyan) · `#10B981` (success/green) · `#F59E0B` (warning/amber) · `#E2E8F0` (text)
**Fonts**: DM Sans (body) + Space Grotesk (headings) + JetBrains Mono (notation)
**Layout**: Hero with molecular visualization, card grid for pipeline, timeline for roadmap
**Motion**: Subtle reveals, spring for interactive 3D, reduced motion mandatory.

## 15. Ink & Paper

**Mood**: Typographic, intellectual, publication-quality
**Best for**: Long-form content, essays, academic blogs, book sites
**Colors**: `#FAF9F6` (bg) · `#1C1917` (ink) · `#78716C` (muted) · `#B91C1C` (accent) · `#D6D3D1` (rule)
**Fonts**: Newsreader (body) + Instrument Serif (headings)
**Layout**: Narrow column (max-w-2xl), large body text (18px+), generous line-height
**Motion**: None. Let the typography work.
